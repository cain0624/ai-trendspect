# 明势 TrendSpect | AI 金融趋势洞察平台

数据驱动型科技资讯分析站：AI 量化解读、实时趋势可视化、事件归因预测。黑场电影感 + 终端等宽 UI，PC 大屏优先，移动端自适应。

## 运行

方式一：直接双击 `index.html` 用浏览器打开。

方式二：本地静态伺服（推荐，交互完整）：

```bash
cd "/Users/cain/Documents/ChatGPT/网站"
python3 -m http.server 8123
```

然后访问 `http://localhost:8123/`。

注意：如果 8000 端口报 "Address already in use"，说明已有其他服务占用（例如本机可能还跑着古伞文化馆的预览服务）。换一个端口即可，例如上面的 8123，或者先停掉占用 8000 的服务。

## 目录结构

```text
index.html          页面结构（6 大核心模块 + 首屏 + 合规栏）
css/style.css       设计令牌、布局、深浅双主题、动效、响应式
js/data.js          模拟演示数据（快讯、资金流、图谱、预测、专栏）
js/charts.js        ECharts 图表封装（含主题重建与 PNG 导出）
js/app.js           交互层（SpecularButton 镜面高光按钮、弹层、图谱联动、环形菜单等）
vendor/echarts.min.js  本地化 ECharts（离线可用）
vendor/fonts/       本地化 Sora 与 JetBrains Mono 字体
```

## 功能模块

1. 实时快讯：分类标签、24h/7天/30天回溯、AI 事件权重、关联推荐
2. 趋势大盘：资金流曲线（日/周/月）、板块热力图、全球市场对比、政策事件叠加，支持缩放、下钻与高清导出
3. 事件因果图谱：政策 → 产业 → 资金 → 股价传导链，点击节点展开上下游与历史复盘
4. 深度专栏：短期研判 / 中长期趋势，结构化排版
5. 预测模型：情绪评分、景气度排名、风险预警、历史回测（横向通栏，右侧与上方卡片对齐）
6. 订阅 & 工具箱：邮件订阅、自定义赛道关注、数据集与报告下载

## 说明

- 所有行情、事件、预测数据均为模拟演示数据，用于展示交互与视觉，不代表真实市场信息。
- 全站固定风险提示：内容不构成投资建议，市场有风险，投资需谨慎。
- 仅深色模式（深浅切换已移除）。
- 首屏为 LightTunnel 移植：WebGL 深蓝光隧道（光纤电缆 + 脉冲流光 + 胶片颗粒），消失点随鼠标视差漂移，减弱动效时渲染静态帧；主文案「AI Trends」为 ParticleText 移植（粒子散聚成字在页面进入时自动触发一次、hover/滑动改为高斯脉冲环波动（无高频振荡，彻底无抖动）、粒子为蓝绿色科技柔边贴图（`#5fc9c4` 基底 + `#d9fff5` 浅绿光感）+ 指针排斥 + 呼吸漂移，字号 `clamp(2.8rem, 10.75vw, 7.5rem)` / 800，粒子尺寸 1.5、采样密度 3，主文案下移 80px、副文案下移 32px、主副标题与画廊整体上移 40px），副文案「聚合&分析全球AI大事件」；首屏居中依次为：主/副文案 → 6 张概念化蓝调素材手风琴画廊（AccordionGallery 移植，16:9，hover 展开、进入视口后每 3 秒自动轮播、点击定位到对应模块 1-6）→ 下滑箭头按钮（easeInOutCubic 缓动滚动至首屏模块，吸附到导航栏下方 24px）；首屏底部带柔和渐变衔接下方内容区。
- 首屏为固定视差背景：`position: fixed` 锁定在视口顶部不随滚动移动，页面内容（`main`）整体下移 100vh 并覆盖其上滚动；首屏内文案/画廊随滚动以不同速率缓动漂移（指数缓动追帧），全站视差均带缓动曲线；模块滚动不吸附，锚点跳转统一对齐到导航栏下方 32px（`scroll-margin-top: calc(var(--nav-h) + 32px)`）；模块卡片底部带蓝色光效阴影，呈现浮起感。
- 首屏标语与各模块标题为 WarpText 移植：鼠标移上出现玻璃折射与波纹，视口懒加载控制 WebGL 上下文数量。
- 导航与输入/图标控件为毛玻璃；每个模块为独立毛玻璃卡片（透明度 6%，hover 降至 3.5%，标题距顶 60px、内容距底 40px、模块间距 32px、模块两侧留 36px、副标题距内容 48px、模块内卡片间距 24px、卡片圆角 16px）；所有按钮/图标按钮为全圆角；页面背景为固定不随滚动移动的多层蓝色光晕 + 微网格/粒子层（减弱动效时静止），毛玻璃卡片透出背景光效；首屏与内容区衔接处通过渐变 + 背景柔光桥接（首屏模块锚定在头图底部，无缝隙）。
- BorderGlow 移植（仅轮播卡片）：2px 边框走光动画——页面进入时默认卡片播放一遍、自动轮播展开新卡片时播放一遍、鼠标 hover 时持续循环扫动（离开停止），均通过 2 层环形遮罩严格限定在边框上，卡片内部（图片/文案）不受任何光效影响；轮播图片常彩、无收起变暗等容器内颜色动画，展开态文案底部为 36px 黑色 40% 蒙层，文案在蒙层内上下居中，无蓝色装饰条。
- 所有 ECharts 图表禁用缩放：资金流图无 dataZoom、事件图谱 roam 关闭，仅保留 hover 提示与导出。
- 性能优化：8 张图表改为进入视口才懒加载（打开页面 0 张初始化）；粒子文字去掉逐帧 shadowBlur、空闲时降到 30fps、切后台暂停；光隧道与 WarpText DPR 1.5；按钮镜面与全站视差循环 30fps 节流；减弱动效时粒子文字静态绘制一帧。粒子文字清晰度优化：DPR 2、粒子上限约 1900、柔边贴图绘制收紧、涟漪波动用平滑起落包络（无抖动）。
- 移动端菜单为圆形 clip-path 展开动画，汉堡按钮带 X 形变。
- 所有 `.btn` 按钮为 SpecularButton 移植：圆角毛玻璃 + WebGL 镜面高光描边，指针 250px 内靠近渐显并跟随光标，触摸设备自动旋转扫描，减弱动效时自动降级。
- 页面滚动带呼吸感全站视差：首屏文案、画廊、每个模块/卡片/面板/页脚按层级深度以不同速率缓速漂移（独立 `translate` 属性叠加，不覆盖 hover 与入场动效），动态渲染的快讯卡片也会自动纳入视差；底部为整张大毛玻璃卡片包住页脚。
- 动画遵循 `prefers-reduced-motion`，系统开启减弱动态效果时自动降级。
